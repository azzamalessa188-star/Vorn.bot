# Vorn.bot

> **Vorn.bot — Your bots. Your workspace. Always within reach.**

منصة سحابية لإنشاء وإدارة بوتات الذكاء الاصطناعي وتشغيلها داخل مساحات عمل Linux مستمرة، مع إمكانية متابعة التنفيذ والتدخل اليدوي عند الحاجة.

## نظرة عامة

لا يقتصر Vorn.bot على واجهة محادثة؛ بل يهدف إلى منح كل بوت مساحة عمل فعلية يستطيع من خلالها استخدام المتصفح والطرفية والملفات والأدوات المصرّح بها لتنفيذ مهام متعددة الخطوات. يحتفظ كل بوت بهويته ومحادثاته وسياق عمله، بينما يستطيع المستخدم مراقبة نشاطه وأخذ التحكم في البيئة ثم إعادة التنفيذ إليه.

## الفكرة الأساسية

يجمع Vorn.bot بين أربعة عناصر:

1. **هوية مستقلة لكل بوت:** اسم ووصف وأفاتار ومحادثة وسياق خاص.
2. **تنفيذ فعلي:** استخدام أدوات مثل المتصفح والطرفية والملفات ضمن الصلاحيات الممنوحة.
3. **بيئة سحابية مستمرة:** تشغيل المهام بعيداً عن جهاز المستخدم مع تخزين دائم وإمكانية إعادة الاتصال.
4. **إشراف بشري:** متابعة التنفيذ وإيقافه وأخذ التحكم ثم إعادته إلى الوكيل.

## الوظائف الأساسية المستهدفة

- إنشاء عدة بوتات وإدارة إعداداتها وهوياتها.
- محادثة مستقلة وسجل محادثات لكل بوت.
- تنفيذ مهام متعددة الخطوات عبر الأدوات المصرّح بها.
- متصفح وطرفية وملفات داخل مساحة العمل السحابية.
- عرض نشاط البوت وحالته الفعلية.
- مشاهدة بيئة العمل والتحكم بها يدوياً عبر Take Control وResume Agent.
- تخزين دائم وإمكانية استعادة الاتصال.
- سجل استخدام يستند إلى الوظائف الموجودة في OpenMausBot ويُكيّف ضمن Vorn.bot.

> هذه قائمة بقدرات المنتج المستهدف، وليست ادعاءً بأن جميع الوظائف نُفذت أو أصبحت جاهزة للإنتاج.

## أساس الواجهة الأمامية

مستودع [milind-soni/OpenMausBot](https://github.com/milind-soni/OpenMausBot) هو المصدر الأساسي الفعلي للواجهة الأمامية بالكامل، وليس مجرد مرجع تصميمي. ستُبنى واجهة Vorn.bot على قاعدة الكود الموجودة فيه، ثم تُكيّف لتطبيق هوية Vorn.bot ومتطلباته وتُربط بالـ Backend وخدمات المنصة.

يُستبعد مجلد enterprise/ من نطاق الاستخدام. ولا تُستخدم مكوناته أو ملفاته ضمن Vorn.bot. كما لا يعني اعتماد الواجهة أن خدمات Vorn.bot الخلفية أو بيئته السحابية موجودة تلقائياً في المصدر؛ يجب تنفيذها وربطها واختبارها بصورة مستقلة.

## البيئة السحابية المستهدفة

المواصفات المستهدفة لكل مساحة عمل:

- نظام Debian Linux.
- موارد مستهدفة: 1 vCPU.
- ذاكرة: 2 GB RAM.
- تخزين دائم: 40 GB.
- متصفح Chrome أو Chromium.
- طرفية Linux.
- سطح مكتب سحابي وبث مباشر عند تفعيلهما.

هذه أهداف تخطيطية، ويجب التحقق من كفاية الموارد والتكلفة والعزل على بيئة الاستضافة الفعلية.

## الذكاء الاصطناعي والباقات

### Starter — BYOK

تتيح للمستخدم ربط مفاتيح API الخاصة به من المزودين الذين يتم دعمهم فعلياً واختبار تكاملاتهم. يتحمل المستخدم رسوم مزود الذكاء الاصطناعي مباشرة.

السعر المذكور في مواصفات المشروع الحالية: **9.99 دولار شهرياً**.

### Workspace No AI

هذا هو اسم الباقة المعتمد. وهي لا تتضمن نموذجاً مستضافاً أو رصيد API مدفوعاً من Vorn.bot. الاسم ليس معرّف نموذج، ولا توجد ضمن هذه الباقة مواصفات Hosted AI أو حصص توكنات معتمدة.

تفاصيل السعر والاستحقاقات الأخرى لهذه الباقة تحتاج إلى اعتماد صريح قبل تثبيتها في مواصفات الفوترة.

## سجل الاستخدام

يُعاد استخدام سجل الاستخدام الموجود في OpenMausBot بدلاً من إنشاء سجل بديل من الصفر. يتضمن المصدر الأساسي صفحة Usage وسجل History مع تجميع بحسب البوت والنموذج والشخص واليوم ومحرك التشغيل، إضافة إلى تصدير CSV. يجب الحفاظ على سلوك المصدر والتحقق من ربط التسجيل الخلفي داخل Vorn.bot قبل وصف التكامل بأنه مكتمل.
